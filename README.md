# GATE 2027 Mock Test Trainer

This repository is organized as a monorepo. The question-extraction pipeline lives in `pipeline/`, Supabase database assets live in `supabase/`, and the web app will be added under `web/` later.

## Project areas

- `pipeline/` — Python tools for extracting and preparing GATE questions.
- `web/` — reserved for the future Vite/React application; it is intentionally not scaffolded yet.
- `supabase/` — database schema and row-level security policies.

See each directory's README for setup and run instructions.
